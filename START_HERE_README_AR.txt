دليل التشغيل — موقع CoCo Trading + لوحة تحكم شغّالة فعلياً
================================================================

شو تم إضافته؟
--------------
1. لوحة أدمن حقيقية:
   - تسجيل دخول فعلي (بكلمة مرور مشفّرة)، مش مجرد نموذج شكلي.
   - أي صفحة بلوحة الأدمن محمية: ما تفتح إلا بعد تسجيل دخول صحيح.
   - كل روابط القائمة الجانبية (Dashboard, Products, Orders...) أصبحت تنقّل فعلياً بين الصفحات.
   - زر Logout شغّال فعلياً.

2. صفحة "Products" بلوحة الأدمن (admin/products.html) أصبحت تدير منتجات حقيقية:
   - إضافة منتج (اسم، فئة، وصف، MOQ، مدة تسليم، تغليف، شحن، صورة، وحالة نشط/غير نشط).
   - تعديل أو حذف أي منتج.
   - الحقول المتعلقة بالسعر/المخزون شِيلت لأنو الموقع عرض بالجملة (Wholesale) مش متجر بيع مباشر.

3. الموقع العام (index.html, products.html, product-details.html...):
   - أي منتج يضيفه الأدمن ويكون "Active" بيظهر تلقائياً لكل زوار الموقع، بنفس تصميم الموقع الحالي تماماً.
   - إذا صنف فيه أكثر من منتج، تظهر شبكة منتجات بنفس تصميم كروت التصنيفات، وبالضغط على أي منتج بتفتح صفحة تفاصيل خاصة فيه.
   - إذا صنف ما فيه ولا منتج مضاف لسا، بتظهر المحتوى الافتراضي القديم (الموقع ما بينكسر أبداً حتى قبل إضافة أي منتج).
   - الموقع لسا "عرض فقط" — ما في سلة شراء، ما في دفع، بس زر "Request a Quote" يوجّه لصفحة التواصل (زي ما كان).

4. صلّحت أخطاء موجودة أصلاً بالمشروع:
   - ملف صفحة المنتجات بالأدمن كان اسمه غلط (roducts.html بدل products.html) وما كان موجود أصلاً.
   - صفحة admin/orders.html كانت مكرّرة بالغلط جوا نفسها (كودين HTML كاملين ملصوقين ببعض) وهذا كان يخرب عرضها.
   - روابط القائمة الجانبية بلوحة الأدمن ما كانت تنقّل بين الصفحات أساساً.

طريقة التشغيل (لازم يكون عندك Node.js مثبّت — نزّله من nodejs.org لو ما عندك)
--------------------------------------------------------------------------
1. افتح Terminal / موجه الأوامر جوا مجلد المشروع.
2. أول مرة فقط، ثبّت الحزم المطلوبة:
       npm install
3. شغّل السيرفر:
       npm start
4. رح تشوف بالطرفية:
       CoCo Trading site running at http://localhost:3000
5. افتح المتصفح على:
       http://localhost:3000                 → الموقع العام
       http://localhost:3000/admin/index.html → لوحة تحكم الأدمن

بيانات تسجيل الدخول الافتراضية للأدمن
---------------------------------------
اسم المستخدم: admin
كلمة المرور : CoCo@Admin2026

غيّر كلمة المرور فوراً من: لوحة الأدمن > Settings > Security > Update Password.

ملاحظات مهمة
-------------
- الموقع أصبح يحتاج تشغيل السيرفر (npm start) حتى يعمل بشكل كامل، لأنو المنتجات
  الآن مخزّنة بملف بيانات على السيرفر مشترك بين كل الزوار (لا localStorage خاص بكل متصفح).
  فتح index.html مباشرة بدون تشغيل السيرفر بيوقف عمل المنتجات (باقي الموقع بيفتح، بس بدون منتجات حقيقية).
- لنشر الموقع فعلياً على الإنترنت، تحتاج استضافة تدعم Node.js (مثل Render, Railway, Hostinger VPS، إلخ)
  وما راح تشتغل على استضافة استاتيكية بسيطة زي GitHub Pages لأنو صار في سيرفر حقيقي بالخلفية.
- نموذج التواصل (Contact) لسا يحتاج ربط بخدمة بريد فعلية، ما تغيّر بهاد التحديث.
- بيانات المنتجات محفوظة بـ data/products.json وصور المنتجات المرفوعة بـ assets/products/.
